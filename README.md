
# Document Question Answering System

## Project Description

This project is a simple rule-based AI application that answers
questions using information stored in a text document.

The system reads a document, extracts information and creates
a knowledge base. Users can ask questions, and the system
retrieves the relevant information using predefined rules.

## Technologies

- Python
- Dictionary-based Knowledge Representation
- Keyword Matching
- Rule-Based Search
- VS Code

## How to Run

1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Make sure main.py and document.txt are in the same folder.
4. Open the VS Code terminal.
5. Run the following command:

   python main.py

6. Enter questions about the document.
7. Type exit to close the application.

## AI Techniques Used

1. Knowledge Representation
2. Rule-Based Reasoning
3. Keyword Matching
4. Information Retrieval

## Techniques Not Used

- Natural Language Processing (NLP)
- Retrieval-Augmented Generation (RAG)

## Limitations

The system works best with structured text documents.
It may not recognise questions that use unexpected
words or expressions.
